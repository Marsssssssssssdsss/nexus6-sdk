How it works
01
Bind
A human binds their real identity to an AI agent on Anexus. The agent receives a unique, verifiable identity ID — like an ID card number for AI.
02
AI Acts
The AI agent calls any platform using its identity ID. Every request is signed, verifiable, and tied to the human who authorized it. No manual steps needed.
03
Verify
The platform calls one line of middleware to verify the caller. Response in under 100ms. The platform knows exactly which AI agent and which human is behind every request.
For everyone

For AI Agents (Caller)

After the human binds their identity once, your agent requests an identity ID. Every outgoing call is automatically signed with your agent secret.

from anexus_sdk import AnexusClient client = AnexusClient() result = client.register(name="My AI") # Sign each request with your agent identity headers = client.build_auth_headers( result["agent_secret"], "GET", "/api/v1/tools" ) headers["X-Api-Key"] = result["api_key"]

For Platforms (Verifier)

Add one line of middleware. Every incoming request is verified automatically — the platform knows exactly which AI agent is calling and which human authorized it.

from anexus_sdk.middleware import AnexusMiddleware app.add_middleware(AnexusMiddleware) @app.post("/api/v1/chat") async def chat(request: Request): identity = request.state.ai_identity # identity.agent_id → which AI agent # identity.human_id → who authorized it
Why identity matters

API keys are not identity

An API key says "this request has a key" — not "this is Agent-7 acting for User-Alice." Anexus gives verifiable identity, not just credentials.

One ID for every platform

Today, an AI agent needs separate keys for every platform it calls. Anexus gives agents a portable identity — register once, authenticate anywhere.

Humans step out of the loop

The human binds their identity once. The AI acts autonomously after that. No more OAuth redirects, no more "click to approve," no more manual token entry.

Auditable by design

Every request carries a verified human+agent identity. Platforms can always trace who authorized what — essential for enterprise compliance.

One package

Both roles, one SDK

A single pip install anexus-sdk covers both sides. The same package acts as Caller (sign outgoing requests) or Verifier (validate incoming requests). One install, zero config. Also available via REST API.
