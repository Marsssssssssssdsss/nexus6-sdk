# Anexus Examples

Complete integration examples for different frameworks and languages.

## Python

| Example | Framework | Role | Description |
|---------|-----------|------|-------------|
| [flask_platform.py](python/flask_platform.py) | Flask | Platform | Verify auth codes in a Flask API |
| [fastapi_platform.py](python/fastapi_platform.py) | FastAPI | Platform | Verify auth codes in a FastAPI API |
| [ai_agent.py](python/ai_agent.py) | — | AI Agent | Generate codes as an AI agent |

## JavaScript

| Example | Framework | Role | Description |
|---------|-----------|------|-------------|
| [express_middleware.js](javascript/express_middleware.js) | Express.js | Platform | Verify auth codes via middleware |

## Running examples

Each Python example can be run directly:

```bash
pip install anexus-sdk anexus-verify
python examples/python/flask_platform.py
```
